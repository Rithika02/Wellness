# Wellness Cards

A premium, calming web application for sending stress relief cards.

## Features
- **Soothing Aesthetic**: Soft sky blue background with cloud-like animations.
- **Glassmorphism UI**: Modern, translucent interface elements.
- **Multiple Themes**: Select from Zen Garden, Deep Ocean, Quiet Forest, and Starry Night.
- **Interactive Flow**: Simple process to select a card, write a message, and "send" peace to a recipient.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## How to Use
1. Open `index.html` in any modern browser.
2. Choose a card theme.
3. Enter the recipient's name and your calming message.
4. Click "Send Calm" to share a moment of peace.
